# 広島民泊物件検索 第8弾

## 今回の変更

### 1. 広島市公式の既存民泊・旅館業物件をDB化
毎回、広島市公式サイトから最新PDFを取得します。

- 住宅宿泊事業法に基づく届出施設一覧
- 旅館業法に基づく許可施設一覧

PDFはGitHubに固定保存せず、実行時に最新ページから取得する方式です。

### 2. 集合住宅は公式一覧との一致を必須化
アパート・マンション等は、SUUMO / HOME'S / at home で見つかっただけでは候補にしません。

次のいずれかに住所・建物名等が一致する場合だけ採用します。

- 広島市の住宅宿泊事業（民泊）届出一覧
- 広島市の旅館業許可施設一覧

### 3. 戸建て系は従来通り広く検索
「戸建」「一戸建」「貸家」「テラスハウス」「タウンハウス」「長屋」等と判断した物件は、公式一覧への一致がなくても検索対象にします。

### 4. 賃貸検索ページを集合住宅も含む一般ページへ変更
SUUMO / HOME'S は「戸建て限定」URLではなく、各区の一般賃貸ページを使用します。

そのうえで第8弾のルールで集合住宅を絞り込みます。

### 5. メールに公式一覧の一致情報を表示
一致した候補には、可能な範囲で以下を表示します。

- 住宅宿泊事業 / 旅館業
- 民泊届出 / 旅館・ホテル営業 / 簡易宿所営業
- 公式一覧の所在地
- 届出・一覧の基準日
- 施設名（取得できた場合）

## 注意

「過去に同じ建物・部屋で民泊/旅館業の届出・許可がある」ことは、「現在募集されている賃貸部屋でそのまま民泊営業できる」ことを意味しません。

賃貸借契約、所有者・管理会社の承諾、管理規約、消防、建築、広島市の条例・届出等は別途確認してください。
