# 広島民泊物件検索 第8.2弾

広島市4区（中区・南区・西区・東区）の賃貸物件を毎日検索し、Gmailで通知するプロジェクトです。

## 第8.2弾の重要な修正

### 1. 広島市公式の民泊一覧PDFの読み取りを強化
第8.1弾では、公式の「住宅宿泊事業法に基づく届出施設一覧」がPDF抽出方法によって大幅に欠落することがありました。

第8.2弾では、PDFを複数の抽出方式で読み取り、取得レコード数が多い方式を採用します。

公式PDFは毎回、広島市公式ページから最新リンクを取得します。

- 住宅宿泊事業法に基づく届出施設一覧
- 旅館業法に基づく許可施設一覧

### 2. 公式一覧との照合をかなり厳格化
第8.1弾のような「十日市ビル」と「西十日市ビル」の部分一致や、「鶴見町」という町名だけを理由に別施設へ一致させる判定をやめました。

第8.2弾では原則として次の条件で照合します。

- 部屋番号一致：部屋番号が一致し、住所・建物名も整合している場合
- 住所一致：番地・号まで一致し、建物名に矛盾がない場合
- 建物名一致：建物名が完全一致する場合（部分一致ではない）

町名だけの一致、住所の一部だけの一致、建物名の部分一致は採用しません。

### 3. 壊れたHOME'Sタイトルを公式照合に使わない
HOME'SなどからHTML断片や画面部品の文字列をタイトルとして取得した場合、それを建物名として公式一覧に照合しないようにしました。

住所が「白島駅…」などのUI断片になっている場合も、公式照合には使いません。

### 4. 戸建ては今まで通り広く検索
戸建・一戸建・貸家・テラスハウス・タウンハウス・長屋などは、公式一覧に載っていなくても候補にします。

### 5. アパート・マンション等は公式一覧一致を必須化
集合住宅などは、SUUMO / HOME'S / at home で見つかっただけでは候補にしません。

広島市公式の民泊届出または旅館業許可一覧との明確な一致が取れたものだけを候補にします。

### 6. 40㎡未満も検索対象
面積による下限は設定していません。

### 7. 家賃上限
月額10万円以下です。

## 注意

公式一覧に同一建物・同一部屋が掲載されていても、「現在募集されている賃貸部屋をそのまま民泊に使える」という意味ではありません。

最終的には、賃貸借契約、所有者・管理会社の承諾、管理規約、消防、建築、広島市の条例・届出等を確認してください。

## GitHub Actions

Secretsは従来通りです。

- `EMAIL_USER`
- `EMAIL_PASS`
- `EMAIL_TO`

毎朝の定時実行に加えて、GitHub Actionsの `Run workflow` から手動実行できます。

メールでは以下を確認できます。

- 広島市公式PDFの取得状況
- 公式DBのレコード数
- サイト別取得状況
- 新着物件
- 値下げ物件
- 公式一覧との照合レベル

## 既存GitHubリポジトリを更新するとき

`seen.json` と `price_history.json` は検索履歴です。

現在のGitHubに既存データがある場合は、8.2のコードへ更新するときも、できればこの2ファイルは現在のものを残してください。空の8.2版で上書きすると、既存候補が「新着」として再通知される可能性があります。
